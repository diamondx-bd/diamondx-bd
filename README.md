# DiamondX BD

Free Fire diamond top-up website — initial responsive front-end prototype.

## Current status
- Bengali mobile-friendly landing page
- Diamond package selection
- Order information form with client-side validation
- Demo order preview only

## Important
This is a static prototype. Orders are **not** sent to a server, payments are not processed, and there is no admin panel yet. Do not send money through this demo. Package prices, verified payment instructions, secure order storage, order tracking, and admin authentication must be configured before launch.

## Deploy with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. Wait for GitHub Pages to publish the site.
